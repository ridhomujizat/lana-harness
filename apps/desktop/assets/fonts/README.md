# Fonts

Geist and Geist Mono by Vercel (https://github.com/vercel/geist-font),
licensed under the SIL Open Font License 1.1 (https://openfontlicense.org).
Copyright 2024 The Geist Project Authors.

The TTF files are decompressed from the WOFF2 files the web UI ships in
web/ui/src/assets/fonts (woff2_decompress), because the native app's text
engine reads TTF/OTF.
